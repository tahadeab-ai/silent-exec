تأكيد تنفيذ الخطوة

محرك التشغيل المحلي (llama-server)

تشغيل محلي كامل مع قواعد GBNF الصارمة وإعادة استخدام ذاكرة KV Cache.

غير مثبت http://127.0.0.1:8080

مستودع النماذج (GGUF)

نماذج مدمجة محسّنة للاستجابة السريعة والأوامر العربية والإنجليزية.

المهارات المدمجة (Built-In Skills)

مهارات حتمية سريعة مفعّلة افتراضياً في SilentExec.

مفعّلة

إنشاء روتين مخصص

احفظ اختصارات متعددة الخطوات في ذاكرة SilentExec لاستدعائها فوراً.

خوادم أدوات MCP

تفعيل بنقرة واحدة للإضافات الرسمية أو ربط خادم MCP مخصص.

ذاكرة SilentExec الدائمة

حقائق وتفضيلات محفوظة محلياً في memory.json تُحقن تلقائياً في سياق الوكيل.

المظهر واللغة والتوجيه

لغة الواجهة
تبديل فوري مع عكس اتجاه الواجهة (RTL / LTR).
المظهر
داكن مريح للعين أو نهاري واضح.
الموجه الحتمي السريع
تنفيذ الأوامر البسيطة في أقل من 15ms قبل استدعاء الذكاء الاصطناعي.

محرك الذكاء الاصطناعي (AI Brain)

اختر بين التشغيل المحلي GGUF أو Ollama أو واجهة OpenAI-Compatible.

جسر الشبكة المحلية (LAN Bridge)

السماح لتطبيق SilentExec Android بإرسال الأوامر إلى هذا الجهاز عبر Wi-Fi.
