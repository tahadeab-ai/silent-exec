# SilentExec NLP Training

This directory contains resources and training recipes for fine-tuning compact LLMs (such as Qwen and Llama architectures) for zero-chatter action emission.

## Guidelines
- Training is conducted via Google Colab with QLoRA to conserve local PC compute resources.
- Generated model checkpoints and quantized GGUF weights are published directly to GitHub Releases (`gh release upload`) rather than stored in git.
